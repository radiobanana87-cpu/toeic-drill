# TOEIC S/A Drill — iOSアプリ化の手順

このフォルダの7ファイルをHTTPS環境に置くだけで、iPhoneのホーム画面から通常のアプリとして起動できます。Mac も Apple Developer 登録も不要です。

```
index.html                 本体（154問 / 767語）
manifest.webmanifest       アプリ名・アイコン・表示方法の定義
sw.js                      オフライン動作用
icon-180.png               iOSホーム画面アイコン
icon-192.png / icon-512.png / icon-512-maskable.png
```

---

## 手順1：GitHub Pages に置く（所要5分・無料）

Service Worker は **HTTPS でしか動作しない**ため、ホスティングが必要です。GitHub Pages が最も手間がかかりません。

1. GitHub にログインし、新規リポジトリを作成する
   - 名前は任意（例：`toeic-drill`）
   - **Public** を選ぶ（Private だと Pages が有料プラン限定になる）
2. リポジトリ画面で **Add file → Upload files** を選び、このフォルダの**7ファイルすべて**をドラッグして Commit する
   - フォルダごとではなく、ファイル単体を7つ置くこと。`index.html` が最上位にある必要がある
3. **Settings → Pages** を開く
   - Source：`Deploy from a branch`
   - Branch：`main` / `/ (root)` を選んで Save
4. 1〜2分待つと `https://<ユーザー名>.github.io/toeic-drill/` が発行される

Public リポジトリなのでURLを知る人は誰でも閲覧できます。学習記録は端末内にのみ保存され、サーバーには一切送信されません。

> **代替**：GitHub を使いたくない場合は Netlify Drop（https://app.netlify.com/drop）にフォルダをドラッグするだけでもHTTPSのURLが発行されます。アカウント登録なしで試せますが、URLは後から変更できません。

---

## 手順2：ホーム画面に追加する

**必ず Safari で開くこと。** Chrome や他ブラウザからはホーム画面追加が正しく機能しません。

1. iPhone の Safari で手順1のURLを開く
2. 画面下部の **共有ボタン**（□に↑）をタップ
3. メニューを下にスクロールし、**「ホーム画面に追加」**をタップ
4. 名前が「TOEIC Drill」になっていることを確認して**「追加」**

ホーム画面のアイコンから起動すると、Safariのアドレスバーやタブが消え、全画面のアプリとして動作します。

## 動作確認

追加後、**機内モードにしてアイコンから起動**してください。問題が表示されれば、オフラインキャッシュが正しく効いています。地下鉄や電波の悪い場所でも使えます。

## 学習記録について

記録（覚えた／要復習）は端末内の localStorage に保存されます。**次の場合に消えます。**

- Safari の履歴・Webサイトデータを消去したとき
- ホーム画面からアプリを削除したとき
- iOS の仕様上、**7日以上まったく起動しなかった場合に消去されることがある**（毎日使うなら該当しません）
- 機種変更したとき（iCloudバックアップでは引き継がれません）

対策として**「記録を書き出す」ボタン**を用意しました。JSONファイルがダウンロードされるので、ファイルアプリや iCloud Drive に保存しておけば、「記録を読み込む」から復元できます。機種変更の前と、月に一度は書き出しておくことを勧めます。

---

## 内容を更新したい場合

新しい問題を追加した `index.html` をGitHubで差し替えれば反映されます。ただし Service Worker がキャッシュを持っているため、**アプリを一度閉じて開き直すと新版に切り替わります**（初回起動時は旧版が表示される仕様）。すぐ反映したい場合は `sw.js` の `const CACHE = 'toeic-drill-v1'` を `v2` に変更してください。

## ネイティブアプリ化について

WKWebView でこのHTMLを包めば `.ipa` として実機にインストールできますが、次の制約があります。

- **Mac と Xcode が必須**
- 無料の個人用証明書では**7日ごとに再ビルド・再インストール**が必要
- App Store 配信には Apple Developer Program（年間 99 USD）が必要

個人利用の範囲では、PWAとの体感差はステータスバーの扱い程度しかありません。上記の手間に見合わないため、PWAでの運用を勧めます。
